# Sunplus UART Loader (Android)

أداة أندرويد مفتوحة المصدر لشحن وفلاش معالجات **Sunplus 1506TV / 1506F / 1506T** عبر كابل **USB OTG** ووصلات التحويل التسلسلي (CH340 / PL2303) مباشرة من الهاتف.

## 🚀 المميزات
- **الاتصال عبر USB Serial:** دعم شريحات CH340, PL2303, FTDI.
- **إدارة BootROM:** إرسال إشارات التزامن والمصافحة التلقائية مع المعالج.
- **حقن ملفات التهيئة (DDR Payload):** دعم تهيئة ذاكرة DDR2 و DDR3.
- **شحن وسحب الفلاشة:** كتابة السوفت وير (WRITE) وسحب النسخة الاحتياطية (DUMP).
- **فحص الملفات:** حساب تلقائي لقيمة CRC32 وحجم الملف.

## 🛠️ متطلبات التشغيل
- هاتف أندرويد يدعم خاصية **USB OTG**.
- وصلة **USB to TTL** (مثل CH340G أو PL2303).
- كابل **RS232 / Jack 3.5mm** المخصص للرسيفر.
